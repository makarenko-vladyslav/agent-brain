# Бібліотека реклами Meta — як я нею користуюсь

> Робочий метод із перевіреним кодом: відкрити через Playwright, доскролити, розібрати картки, і читати тривалість показу як сигнал «це працює». Перевірено 24.08.2026 на ніші renhold/Норвегія — 220 активних оголошень.

Логіну не потребує, API-ключа теж. Все публічне.

---

## Ключ до читання: тривалість = доказ

В Ad Library немає метрик ефективності. Але є дата початку показу, і вона працює замість них: **ніхто не палить бюджет роками на рекламу, що не конвертить.** Оголошення, яке крутиться 900 днів, — це не здогад про робочу формулу, а її підтвердження грошима рекламодавця.

Звідси два сигнали:
- **довго активне** — робоча зв'язка, її формулу варто розбирати;
- **багато оголошень у одного рекламодавця** — він тестує, тобто в нього є бюджет і процес.

Зворотний бік (метод із [[bp-ad-intelligence-and-agent-command-center]]): свіже й швидко замінене — те, що не спрацювало; саме туди заходять із пропозицією переробити.

## URL, який робить усю фільтрацію

```
https://www.facebook.com/ads/library/?active_status=active&ad_type=all
  &country=NO&q=<запит>&search_type=keyword_unordered&media_type=all
```

`country` — двобуквений код (NO, UA, US). `active_status=active` — тільки те, що крутиться зараз. Ще доступні `&sort_data[mode]=total_impressions` і фільтр за датами. Реклама конкретної компанії: її сторінка → About → Page transparency → See all → Ad library.

## Код, що працює (Playwright `browser_evaluate`)

Доскролити — Meta вантажить порціями, за раз віддає ~29 карток:

```js
async () => {
  const sleep = ms => new Promise(r => setTimeout(r, ms));
  let prev = 0;
  for (let i = 0; i < 14; i++) {
    window.scrollTo(0, document.body.scrollHeight);
    await sleep(1400);
    const n = document.body.innerText.split('Ідентифікатор бібліотеки:').length - 1;
    if (n === prev && i > 3) break;
    prev = n;
  }
  return { loaded: prev };
}
```

Розібрати. Картки ріжуться за маркером «Ідентифікатор бібліотеки:», рекламодавець — рядок **перед** словом «Реклама», текст — рядки після нього:

```js
const parts = document.body.innerText.split(/Ідентифікатор бібліотеки:/).slice(1);
const lines = p.split('\n').map(s => s.trim()).filter(Boolean);
const i = lines.findIndex(l => l === 'Реклама');
const advertiser = i > 0 ? lines[i-1] : null;
```

⚠️ **Маркери мовозалежні.** Інтерфейс іде мовою браузера — «Ідентифікатор бібліотеки» / «Library ID», «Реклама» / «Sponsored». Перед розбором подивитись `innerText`, а не вгадувати.

⚠️ **Дати теж локалізовані** («21 лист. 2024 р.») — розбирати таблицею скорочень місяців, `Date.parse` тут не працює.

## Що з цього виходить — приклад на реальній ніші

Renhold, Норвегія, 24.08.2026: 220 активних, розібрано 54.

Найдовші показники: Poleringskongen — **985 днів** без перерви; Optimal Fasadevask — 810 днів і два оголошення; M-K Renhold — 641; Lykke Hjemme — 544 при трьох оголошеннях; OGR — 542 при чотирьох.

Частота формулювань у текстах: `fasadevask` 20, `tilbud` 15, `befaring` 14, `gratis` 11, `softwash` 8, `uforpliktende` 7, `24 timer` 5, `fast pris` 4.

**Читається так:** ринок продає не «прибирання», а **миття фасаду**, і заходить через **безкоштовний огляд без зобов'язань** (`gratis befaring`, `uforpliktende tilbud`). Диференціація — назва технології (`softwash`), а не якість загалом. Заперечення, яке всі знімають наперед: невизначена ціна — звідси `fast pris` і `pristilbud innen 24 timer`. Зустрічається й пакетування: «замов миття даху — миття фасаду в подарунок».

## Де це вживати

- **Перед генерацією сайту в ніші** — які саме послуги виносити вперед і якою мовою про них говорити. Ринок уже оплатив цю відповідь.
- **CTA сайту** — брати той, до якого ніша привчила (для норвезького клінінгу це `gratis befaring`, а не «зв'яжіться з нами»).
- **Аргумент у пітчі** — «ваші конкуренти третій рік крутять оголошення про миття фасаду, а на вашому сайті цієї послуги не видно».
- **Заперечення, які треба зняти на сторінці** — вони прямо в текстах конкурентів.

⚠️ Це дані про **рекламу**, не про попит. Скільки людей шукає послугу — окреме питання й окремий інструмент: [[../rules/dont-ask-the-model-what-instruments-measure]].
