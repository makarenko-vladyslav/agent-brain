## Головне: дизайн-система

Автор третього відео підсумовує так: якщо з усього лишити одну думку — це вона. Без системи кожна генерація дає «черговий однаковий нейромережевий сайт»; з нею видно конкретний бренд.

**Із чого збирається:** GitHub-проєкт, локальна кодова база, файл Figma, або просто візуальні асети — логотип, фото продукції, **скріншот чужого сайту як референс натхнення**.

**Що всередині:** палітра, типографіка, іконки, кнопки, картки, правила компонування, анімації, elevations, радіуси, форми й плями, wordmark, навіть тон тексту. Показується не списком кольорів у вакуумі, а одразу на прикладі реальної сторінки — кнопка поруч із карткою й заголовком.

**Головна вигода — повторне використання.** Одна система → інтернет-магазин, презентація для партнерів, рахунок, схема доставки, меню, Instagram-пости, мобільний додаток. Формати різні, візуально — один бренд, і **в жодному наступному запиті не треба пояснювати, як бренд має виглядати**.

Правило звідти ж: якщо шрифт або елемент не пасує бренду взагалі — правити **в самій системі**, а не в конкретному макеті. Тоді всі майбутні проєкти збираються вже виправленими. Одна правка тут дешевша, ніж ловити ту саму помилку в кожному документі.

## Робочий цикл проти generic-вигляду

1. Перша генерація з одного промпту — виходить охайно, але безлико.
2. Знайти референс (Pinterest, Mobbin) — не копіювати, брати як напрямок.
3. Зібрати з нього дизайн-систему.
4. Застосувати до того самого проєкту — результат стає впізнаваним.
5. Далі — точкові правки: коментарі прямо на елементі або ручне редагування як у Figma.

**Економія токенів:** точкові правки коментарем витрачаються значно спокійніше за повну перегенерацію. Коли макет влаштовує — віддати в Claude Code і доводити код там, це дешевше.

## `/design` у Claude Code проти Claude Design

Anthropic випустив офіційний скіл `/design`, який приносить artboard-процес у Claude Code. Створює редагований артефакт: акцентні кольори, відступи, масштаб шрифтів, бічна панель як у Figma, коментарі на канві, шеринг посиланням як у Google Doc.

**Чому Claude Code сильніший** — і це головна відмінність: він бачить твій контекст. Пам'ять, дизайн-системи, бренд-буки, дані бізнесу, власні скіли. Тому один короткий промпт дає точний результат із правильними цифрами. Claude Design натомість — сесія без пам'яті: щоразу питає, що це за бізнес, і повертає дефолтні шрифти й чорно-синю палітру.

Ще дві переваги Claude Code: можна поєднати `/design` із **власними скілами** (згенерувати відео й одразу поставити фоном), і можна **задеплоїти** результат — Claude Design на прохання опублікувати відповідає «зроби це сам».

Не тільки сайти: 3D-об'єкти (обертаються в браузері, кубик Рубика збирається), email-шаблони, мокапи мобільних додатків, презентації, друковані флаєри, діаграми, анімована інфографіка з точним текстом і SVG — там, де відеогенератори пливуть буквами й цифрами.

**Обмін в обидва боки:** з Claude Design у Claude Code (локальний агент, веб-сесія, GitHub, zip), і назад. Логічний поділ: візуальні правки — там, реальна розробка — тут.

⚠️ **Цифри в макетах вигадані.** Якщо не дав реальних даних, модель підставить правдоподібні, щоб показати композицію. Для макета нормально, перед відправкою клієнту — замінити й перевірити.

## Що вже є в цій системі (перевірено 24.08.2026)

- **Інструмент `DesignSync` доступний** — читає й оновлює проєкти claude.ai/design, синхронізує локальну бібліотеку компонентів із дизайн-системою по одному компоненту. Порядок викликів жорсткий: read → `finalize_plan` → write/delete.
- **Скіл `/design` від Anthropic — відсутній** у цій інсталяції (Claude Code 2.1.220). Локальний `~/.claude/skills/design/` — це OMC-скіл власника, інша річ. Якщо потрібен саме artboard-процес — перевірити оновлення.

## Higgsfield замінюється агрегатором з оплатою за факт

Higgsfield по суті — обгортка над чужими моделями плюс агрегація доступу. Те саме дають агрегатори, але без місячної підписки:

- **kie.ai** — найдешевший (GPT image 2: 3¢ за 1K, 5¢ за 2K, 8¢ за 4K проти ~31–34¢ у Higgsfield), але бувають перебої під навантаженням.
- **fal.ai** — надійніший, різниця в ціні копійки; розумний дефолт.
- **WaveSpeed** — коли треба нішева модель, якої немає в fal.

Замість підписки — власний скіл, що маршрутизує на найдешевшого доступного провайдера, тримає **ліміт бюджету на прогін**, логує промпти й складає згенероване локально. Практична деталь: без жорсткого ліміту прохання «згенеруй 100 зображень» вижере кредити повністю.

Дві претензії до Higgsfield, які й породили хвилю альтернатив: умови використання, за якими згенероване йде на покращення їхніх моделей, і вікно видалення — після відписки контент зникає, якщо не встиг забрати.

## Claude Cowork у Chrome

Claude працює в бічній панелі браузера на сторінці, де ти **вже залогінений**: читає, клікає, друкує, заповнює форми. Скіли, плагіни й конектори вперше працюють у браузері. Сесії живуть в акаунті, не на машині — почав у вкладці, продовжив із телефону.
