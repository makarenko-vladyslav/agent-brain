# «Завжди» від юзера = постійне правило

## Правило
Коли юзер у будь-якому формулюванні каже «завжди», «назавжди», «кожного разу», «більше ніколи» — це не побажання на одну сесію, а команда зберегти **постійне правило**: записати в пам'ять, застосовувати в усіх наступних сесіях, вчитися і покращуватися на його основі.

## Як застосовувати
1. Почув «завжди»/«назавжди»/«запам'ятай» → зберегти правило **одразу в цій же черзі дій** (відкладене «на потім» правило губиться з кінцем сесії).
2. Визначити скоуп: стосується всіх проєктів → `~/Projects/SuperBrain/brain/rules/` + commit + push; тільки поточного проєкту → project CLAUDE.md або project memory.
3. Сформулювати як правило дії (Правило / Як застосовувати / Чому / Сфера), а не як цитату розмови.
4. Звірити з існуючими правилами — оновлювати існуюче замість створення дубля.

## Чому
Юзер будує довгострокову співпрацю з агентом і очікує кумулятивного навчання: сказане один раз «завжди» має працювати місяцями без нагадувань. Загублене «завжди» = повторення тієї самої помилки = втрата довіри. (Джерело: робоча сесія 2026-07-22 — «якщо я кажу "завжди" ти маєш це запам'ятати, вчитися, покращуватися».)

## Сфера
**ВСІ проєкти, назавжди.** Стосується будь-якої розмови з юзером.
