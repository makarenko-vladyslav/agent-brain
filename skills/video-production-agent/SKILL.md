# Video Production Agent

## Роль
Senior Video Production Engineer — автоматизація повного циклу виробництва відео від сценарію до готового MP4.

### TRIGGERS
- Ключові слова: ElevenLabs, HiggsField, Seedance, FFmpeg, Remotion, CapCut, озвучка, TTS, voice cloning, thumbnail, відеомонтаж, субтитри, SRT, MP4 рендер, анімація сцен, video rendering, 1080p, 60fps
- Задачі: згенерувати озвучку, створити thumbnail, змонтувати відео, анімувати зображення, додати субтитри, конвертувати відео через FFmpeg
- Контекст: коли є готовий сценарій і треба перетворити його на відеофайл, або коли потрібна конкретна технічна операція з відео

### ANTI-TRIGGERS
- Планування контенту, вибір теми, стратегія публікації → content-pipeline-orchestrator
- Пошук відео на YouTube → youtube-search-explorer
- Аналіз чужого відео → youtube-video-analyzer
- Складні Canvas scroll-анімації (не video) → apple-scroll-animation-architect

### SKILL CONFLICTS
- **content-pipeline-orchestrator**: найтісніший зв'язок. Різниця: video-production — технічне "як зробити"; pipeline — стратегічне "що і коли робити"
- **apple-scroll-animation-architect**: обидва працюють з FFmpeg. Різниця: video-production — монтаж відео для YouTube; apple-scroll — Canvas анімації для веб

## Виробничий конвеєр

### Input
- Готовий сценарій (після фільтру вірусності)
- Персонаж (character board)
- Стиль (Family Guy cartoon / реалістичний / тощо)

### Output
- Відео (MP4, 1080p, 60fps)
- Аудіо-трек (MP3)
- Субтитри (SRT)
- Thumbnail (JPG, 1280x720)

## Крок 1: Озвучка

### ElevenLabs API (основний)
- Voice cloning: мін. 30 хв чистого аудіо для Pro
- Емоційні теги: `<laugh>`, `<whisper>`, `<sigh>`
- Параметри: stability 0.5, similarity_boost 0.75
- Вихід: MP3 з таймкодами для кожного речення

### Voicot (дешевий fallback)
- Telegram бот з голосами ElevenLabs
- В 7-10x дешевше
- Оплата криптою або RU-картою

### Google AI Studio (безкоштовний fallback)
- Без лімітів
- Якість нижча, але для тестування ОК

### Правила озвучки
- ЗАБОРОНЕНО: стандартні TTS голоси (причина демонетизації)
- ОБОВ'ЯЗКОВО: унікальний клонований голос
- Темп: природний, з паузами (не робот)

---

## Крок 2: Генерація зображень

### HiggsField AI (основний)
- Модель: Cedere 5.0 або новіша
- Формат: ОБОВ'ЯЗКОВО 16:9 для YouTube
- 1 зображення = 1-2 речення сценарію

### Промпт-шаблон (Family Guy)
```
Create a clean 2D cartoon scene in American animated sitcom style (Family Guy).
Scene: [1-2 РЕЧЕННЯ ЗІ СЦЕНАРІЮ]
Requirements: flat colors, minimal shading, thick outlines, exaggerated proportions
IMPORTANT: NO text, NO subtitles, NO logos
```

### Промпт-шаблон (реалістичний)
```
Cinematic scene: [ОПИС]
Style: photorealistic, 16:9, shallow depth of field, natural lighting
NO text, NO subtitles, NO watermarks
```

### Кількість сцен
- 10-хвилинне відео = ~40-60 сцен
- Кожна сцена = 3-5 секунд після анімації

---

## Крок 3: Анімація

### Seedance 2.0 (основний)
- Статичне зображення → кінематографічна сцена (3-5 сек)
- Multi-reference mode для consistency
- Omni Reference: character sheet + локація + другий персонаж

### HiggsField Animate (fallback)
- Вбудована анімація зображень
- Простіше, але менше контролю

### Правила анімації
- Мінімум 3 секунди, максимум 5 секунд на сцену
- Рух має бути природним (не різкий zoom)
- Для динамічних сцен — більше руху, для спокійних — менше

---

## Крок 4: Монтаж

### FFmpeg + Remotion (програмний, для автоматизації)
```bash
# Зʼєднання сцен
ffmpeg -f concat -safe 0 -i scenes.txt -c copy output.mp4

# Додавання аудіо
ffmpeg -i video.mp4 -i audio.mp3 -c:v copy -c:a aac final.mp4

# Додавання субтитрів
ffmpeg -i final.mp4 -vf "subtitles=subs.srt" -c:a copy output_with_subs.mp4
```

### Remotion (для складного монтажу)
- React-based video rendering
- Програмне додавання зумів, переходів, ефектів
- Autogenerated субтитри через Whisper API

### CapCut (manual fallback)
- Автосубтитри (вбудована нейромережа)
- Зручний UI для fine-tuning
- Pro через VPN + PayPal для України

### Правила монтажу
- Склейки кожні **1-3 секунди** (висока динаміка!)
- Малі зуми (2-5%) для відчуття руху
- Фонова музика обов'язкова (royalty-free)
- Субтитри обов'язкові
- Експорт: 1080p, 60fps, H.264

---

## Крок 5: Thumbnail

### Принципи
- Яскравий, контрастний фон
- Обличчя з емоцією (здивування, шок, радість)
- Максимум 3-4 слова тексту (великий шрифт)
- A/B: генерувати 2-3 варіанти

### Інструменти
- AI image gen (HiggsField/Midjourney) для основи
- Canva API для тексту та фінішу
- Розмір: 1280x720 (16:9)

## Чеклист якості відео

- [ ] Озвучка = клонований/унікальний голос
- [ ] Зображення = 16:9, без тексту/водяних знаків
- [ ] Анімація = 3-5 сек на сцену, плавний рух
- [ ] Склейки < 3 секунди
- [ ] Фонова музика присутня
- [ ] Субтитри додані
- [ ] Вставка з обличчям на початку (5-10 сек)
- [ ] Реальні кадри/footage як розбавка
- [ ] Thumbnail = яскравий, емоційний, <4 слова
- [ ] Загальна тривалість = 10-15 хвилин
- [ ] Експорт = 1080p, 60fps, H.264
