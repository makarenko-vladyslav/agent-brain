### 1. THE "ULTRA-PREMIUM" FOUNDATION (Аура дороговизни)
- **Immersive Canvases**: Відмова від "нудних" пласких фонів. Кожен проєкт має виглядати як захоплюючий "досвід". Використовуй глибокі атмосферні стилі: чистий Dark Mode, кришталевий Light Mode зі складними шумами (1-3% Noise), Texture Overlays, ледь помітні сітки (Grids) або м'яке неонове підсвічування.
- **Снайперський акцент**: Незалежно від палітри, завжди виділяй ОДИН потужний, контрастний акцентний колір (Accent Color) для ключових CTA, метрик та мікро-графіки, щоб скеровувати увагу користувача.
- **Дизайн без обмежень**: Не зациклюйся лише на Bento Box чи Brutalism. Адаптуй стиль під нішу: каліграфічна елегантність для портфоліо чи б'юті, агресивна геометрія для крипти, неоновий мінімалізм для Tech.

#### 1.1 COLOR SCIENCE (Палітра рівня Awwwards)
**Decision framework (3 кроки перед дизайном):**
1. **COLOR TEMPERATURE** → warm/cool/neutral — під емоцію ніші. Warm (amber, coral, terracotta) = довіра, затишок. Cool (blue, teal, slate) = професіоналізм. Neutral warm (cream, sand) = organic, eco.
2. **PALETTE** → обери ОДИН hue → derive тінти/тони через HSL. `hsl(H, 84%, 39%)` = base → `hsl(H, 60%, 85%)` = light → `hsl(H, 90%, 20%)` = deep. Гармонія автоматична.
3. **60-30-10** → 60% dominant surface (фон) / 30% secondary (картки, елементи) / 10% accent (CTA, badges).

**Залізні правила:**
- **Ніякого чистого сірого**: `#808080` = мертвий. Neutrals ЗАВЖДИ мають undertone: warm gray (`hsl(30, 5%, X%)`) для теплих ніш, cool gray (`hsl(220, 8%, X%)`) для холодних.
- **High contrast (dark bg + neon accent)** = luxury/premium/bold. Використовуй для бізнесів що хочуть виглядати дорого.
- **CTA = максимальний контраст до фону**. Темний фон → яскравий accent. Світлий фон → deep saturated. Ніколи subtle CTA.
- **Текст на зображеннях = ЗАВЖДИ overlay** (`bg-black/40` мінімум, краще gradient від `bg-black/60` до `transparent`).

### 3. TYPOGRAPHIC SCULPTING & RHYTHM (Скульптурування тексту)
- **Perfect Text Blocks**: Категорична заборона на "рвані", незбалансовані абзаци або "висячі" слова (widows/orphans). Текст (desc) завжди має формувати красивий прямокутник або візуально збалансований блок.
- **Типографічний ритм**: Завжди задавай чіткий ритм через типографіку (напр., через уніфіковані префікси, лінійки, трекінг/кернінг).
- **Адаптивний Vibe**: Використовуй властивості шрифту для передачі емоції: масивний tight-tracking для впевненості/SaaS, або розширена каліграфія з великим letter-spacing для luxury-ніш.

#### 3.1 FONT PAIRING STRATEGY
**Правило двох**: Display font (заголовки, характер) + Body font (текст, читабельність). НІКОЛИ 3+ шрифтів.
- **Контраст ваги драматичний**: H1 = `font-weight: 800-900, letter-spacing: -0.03em` (потужність) vs Body = `font-weight: 400, letter-spacing: 0` (спокій).
- **Responsive type scale через clamp()**: `H1: clamp(2.5rem, 6vw, 5rem)`, `H2: clamp(1.8rem, 4vw, 3rem)`, `Body: clamp(1rem, 1.1vw, 1.125rem)`.
- **Leading (line-height)**: Заголовки `1.05-1.15` (щільно, як постер). Body `1.6-1.75` (повітря). Captions `1.4`.

**Font pairing по ніші (стратегія, не hardcode):**
- Construction/Industrial → geometric sans (Inter, Outfit, Geist) + mono тільки для specs/цифр
- Beauty/Salon → elegant serif (Playfair Display, Cormorant) + clean sans
- Cafe/Restaurant → warm rounded sans (Nunito, Quicksand) або display serif
- Medical/Legal → trustworthy sans (Plus Jakarta Sans, DM Sans)
- Luxury/Premium → thin serif або condensed sans з extreme tracking
- Tech/SaaS → modern geometric (Geist, Inter, Satoshi) + monospace accents

### 4. "ALIVE" UI & STAGGERED ORCHESTRATION (Живий інтерфейс)
- **The 60fps Breathing Rule**: Інтерфейс має жити навіть тоді, коли юзер нічого не робить (Idle State). Вбудовані повільні CSS Marquee (біжучі стрічки), лінії, що малюються, ефекти дихання тіней (`Glow`) чи магнітні кнопки.
- **Каскадна поява (Staggered)**: Елементи ніколи просто не "з'являються" всі разом. Застосовуй хвильові 60fps GPU-анімації (FadeInUp, SlideIn). Спочатку завантажується заголовок, потім текст, потім UI-елементи з мінімальними затримками (`animation-delay`).
- **Framer Motion Physics**: Завжди застосовуй `spring`, ніякого плоского лінійного `ease`.

#### 4.1 ANIMATION TOOLKIT (Beyond Framer Motion)
**Tier 1 — Завжди надійно, величезний вау-ефект:**
- **SVG path animations**: `stroke-dasharray` + `stroke-dashoffset` для ліній що малюються при скролі, morphing форм, лого-анімації. `pathLength: 0 → 1` через Framer Motion.
- **CSS @keyframes**: gradient shifts (`background-position` animation), floating elements, breathing glows, aurora/mesh gradient backgrounds.
- **Canvas 2D particles**: Фоновий particle field з connection lines, зірки, abstract dots. `requestAnimationFrame` loop.
- **Animated SVG mockups**: Замість статичного скріншоту → SVG елементи з анімованими даними (графіки, KPI, progress bars).
- **CSS transforms + clip-path**: Reveal animations, split-screen transitions, diagonal wipes.

**Tier 2 — Преміум, потребує чистої реалізації:**
- **Three.js (@react-three/fiber)**: Floating geometry, abstract blob (noise displacement), mesh gradient sphere, 3D product showcase.
- **Animated gradient mesh backgrounds**: CSS `conic-gradient` + `radial-gradient` з animation — як Stripe/Linear.
- **Text reveal animations**: Split-text effects (слово по слову), character stagger, typewriter.
- **Marquee tickers**: Нескінченна CSS-стрічка з логотипами/фразами (transform: translateX + animation).
- **Mouse-reactive parallax**: `useMotionValue(mouseX/mouseY)` → subtle shift layers (3-5px max).

**Tier 3 — Для максимального WOW (складна реалізація):**
- **Custom WebGL shaders (GLSL)**: Noise displacement, water effects, generative backgrounds. Через `<canvas>` + raw WebGL або Three.js ShaderMaterial.
- **Three.js складні сцени**: Environment maps, PBR materials, post-processing (bloom, chromatic aberration).
- **Procedural generation**: Generative SVG patterns, fractal backgrounds, voronoi diagrams.

**Вибір техніки під нішу (НЕ одна формула для всіх):**
- Mesh gradients → підходить ВСІМ (різні кольори під нішу)
- Noise overlay SVG → dark/tech/luxury. НЕ для дитячих, eco, pastel
- 3D tilt → product showcases, mockups. НЕ для кожної картки
- Grid floor pattern → tech, architecture, industrial. НЕ для beauty, food
- Particles → tech, SaaS, futuristic. НЕ для organic, handmade
- SVG path draw → ЗАВЖДИ (лого, border reveals, illustrations)
- Staggered reveals → ЗАВЖДИ. Це база.
- Scroll parallax → ЗАВЖДИ. Це база.

### 5. UX AUDIT & CONVERSION ANALYSIS (Аналіз рівня Pentagram/Fantasy)
Коли аналізуєш чужий сайт — мисли як топ 0.0001% дизайнерів. Не "H1 відсутній", а повна деконструкція конверсійної архітектури. Конкретні правила побудови лендінгів → секція 6.

#### 5.1 CONVERSION ARCHITECTURE (Воронка конверсії)
- **Funnel Mapping**: Де саме у воронці Impression → Interest → Desire → Action відвалюється клієнт? Кожен крок — окремий аналіз.
- **Friction Inventory**: Кожна зайва дія (скрол, клік, пошук телефону) = тертя. Квантифікуй: "3 кліки до форми замість 1 = ~40% drop-off".
- **Exit Intent Analysis**: Чому користувач закриває сторінку? Немає CTA? Занадто багато тексту? Не зрозуміло що робити далі?
- **Dead Zones**: Ділянки сторінки де нічого не конвертує — пуста порожнеча між секціями, footer без CTA.

#### 5.2 FIRST 5-SECOND TEST (Перше враження)
- **Above-the-Fold ROI**: Що займає дорогоцінний перший екран? Оцінюй за правилами секції 6.1.
- **Value Proposition Clarity**: За 5 секунд юзер повинен зрозуміти: ХТО ви, ЩО робите, ЧОМУ обрати вас, ЩО робити далі. Якщо хоч одне не зрозуміло — fail.
- **Visual Focal Point**: Куди перший погляд? Якщо не на CTA або ключовий офер — ієрархія зламана.
- **Cognitive Load**: Скільки ментальної енергії вимагає перший екран? Закон Хіка: >7 елементів вибору = параліч.

#### 5.3 PSYCHOLOGICAL TRIGGERS (Cialdini Framework)
Кожен сайт оцінюй через 6 принципів переконання:
- **Reciprocity**: Чи дає сайт щось безкоштовне ДО запиту на покупку? (прорахунок, консультація, гайд)
- **Commitment & Consistency**: Чи є міні-кроки? (quiz → калькулятор → форма). Мікро-конверсії перед макро. → див. секцію 6.2.
- **Social Proof**: ЯКИЙ тип proof? Google Reviews = слабкий. Відео-відгуки = потужний. Case studies з цифрами = найпотужніший. → шари довіри в секції 6.3.
- **Authority**: Сертифікати, роки досвіду, "500+ проєктів", партнерства. Чи є хоча б 3 сигнали?
- **Scarcity**: Реальний дефіцит чи маніпуляція? → правила в секції 6.6.
- **Liking**: Чи є людське обличчя? Фото команди? Сайти без людей конвертують на 30-40% гірше.

#### 5.4 COGNITIVE & BEHAVIORAL ANALYSIS (Нейродизайн)
- **F/Z-Pattern Compliance**: Чи відповідає лейаут природному скануванню очей? CTA поза зоною сканування = невидимий.
- **Content-to-Chrome Ratio**: Скільки екрану = корисний контент vs навігація/логотип/порожнеча. Ідеал: >60% контент.
- **Information Density**: 957 символів на головній = катастрофа. Мін. для SEO = 1500+ слів. Мін. для довіри = 8+ секцій.
- **Gestalt Principles**: Proximity (групування), Similarity (консистентність), Closure (завершеність). Порушення = хаотичний вигляд.
- **Miller's Law**: 7±2 елементів в навігації. 9+ пунктів меню = когнітивне перевантаження.

#### 5.5 COPY QUALITY ASSESSMENT (Конверсійний копірайтинг)
- **Benefit vs Feature**: "Перевірена якість" = фіча (нікого не чіпає). "Ваш дах витримає 50 років без ремонту" = benefit (б'є в біль).
- **PAS/AIDA Framework**: Чи є Pain → Agitate → Solution? Чи просто список послуг без емоції?
- **Voice Consistency**: Однаковий тон по всьому сайту? Формальний хедер + розмовний footer = дисонанс.
- **Readability**: Довжина речень <20 слів. Прості слова. Чи говорить як людина чи як робот/юрист?

#### 5.6 VISUAL CONSISTENCY AUDIT (Візуальна система)
- **Color Palette Cohesion**: Скільки кольорів? Є система чи хаос? >4 основних кольори = візуальний шум.
- **Typography Hierarchy**: Чітка драбинка H1 > H2 > H3 > body? Один sans-serif + один accent = ідеал.
- **Spacing System**: 4/8px grid? Одинаковий padding/margin чи "на око"? Неконсистентні відступи = дешевий вигляд.
- **Grid Alignment**: Чи все вирівняне? "Плаваючі" елементи = непрофесійність.
- **Icon & Image Consistency**: Один стиль іконок (outline vs filled vs emoji)? Змішування = хаос.

#### 5.7 REVENUE IMPACT ESTIMATION (Бізнес-вплив)
Не абстрактне "ви втрачаєте клієнтів", а конкретне:
- "При ~500 відвідувачів/міс і конверсії 1% (vs індустрійних 3-5%) ви недоотримуєте ~15-20 заявок/міс"
- "Кожна відсутня форма = ~30-40% втрачених вечірніх лідів"
- Завжди прив'язуй до грошей: "20 втрачених заявок × середній чек $2000 = $40,000/міс потенційних втрат"

### 6. CONVERSION LANDING PAGE PATTERNS (CRO-архітектура)
Коли будуєш лендінг — ніша, місто та контактні дані приходять як параметри. Кожен компонент = конверсійний механізм.

#### 6.1 HERO SECTION
- **ЗАБОРОНЕНО**: H1 що констатує проблему ("Поламалось авто?"). Клієнт шукає РІШЕННЯ.
- **ЗАБОРОНЕНО**: Hero без CTA або з CTA "Дізнатись більше". Логотип > 15% висоти екрану.
- **ОБОВ'ЯЗКОВО**: H1 = потужний офер ("Фіксована ціна без прихованих платежів"). CTA = конкретна дія ("Отримати розрахунок"), а не "Надіслати".
- **ОБОВ'ЯЗКОВО**: Клікабельний телефон у header (`tel:` link) + floating action button для мессенджера на мобайлі.

#### 6.2 INSTANT CONVERSION FLOW (Multi-Step Funnel)
Проста форма з "Надіслати / Ми передзвонимо за 24 год" вбиває конверсію.

**Патерн воронки:**
- **Крок 1**: Вибір послуги/проблеми (великі клікабельні картки).
- **Крок 2**: Локація/адреса (автозаповнення).
- **Крок 3**: Вибір дати та часу (слоти, не дейтпікер).
- **Прогрес-бар**: Завжди. Commitment bias = юзер не кине на 2-му кроці.
- **Мікрокопія**: Під кожним кроком — "Безкоштовно, без зобов'язань".

#### 6.3 TRUST ENGINEERING (Шари довіри)
| Шар | Де | Що показувати |
|-----|----|--------------|
| **Instant Trust** | Hero, під H1 | "500+ проєктів", "12 років", зірки |
| **Social Proof** | Після hero | Відгуки (avatar + ім'я + зірки + текст), стиль Google Reviews |
| **Authority** | Третина сторінки | Сертифікати, ліцензії, партнерства |
| **Human Face** | Середина | Фото РЕАЛЬНОЇ команди (→ generate_image для демо) |
| **Guarantee** | Перед фінальним CTA | "100% повернення якщо не влаштує" |

#### 6.4 OBJECTION HANDLING (Зняття заперечень)
Відповідай на страхи ДО того, як їх озвучать. Картки або акордеон:
1. **Безпека** · 2. **Гарантії** · 3. **Ціна** (прозорість) · 4. **Термін** · 5. **Процес**
Копірайт — конкретний для ніші. Клінінг: "Працюємо тільки у вашій присутності". Юристи: "256-bit шифрування документів".

#### 6.5 MOBILE CRO (60-70% трафіку)
- Touch targets ≥ 44×44px · Thumb Zone для CTA (нижня третина) · Sticky CTA на мобайлі
- Компактний Header: логотип + бургер + телефон, ≤ 60px висота
- No Horizontal Scroll — категорична заборона

#### 6.6 URGENCY & SCARCITY
Тільки правдиві тригери:
- **Реальний дефіцит**: "Залишилось 3 вікна на цей тиждень" (динамічний лічильник).
- **Сезонність**: countdown timer до кінця акції.
- **ЗАБОРОНЕНО**: Фейкові таймери що перезапускаються.

#### 6.7 VISUAL CONTENT RULES
- **ЗАБОРОНЕНО**: Тривожні фото процесу (бруд, хімікати). Порожнє обладнання без людей. Generic стокові фото ("business handshake").
- **ОБОВ'ЯЗКОВО**: Фокус на РЕЗУЛЬТАТ: щасливі клієнти ПІСЛЯ послуги, Before/After. Реальні працівники в уніформі.
- **Performance**: WebP, `loading="lazy"`, `srcset`, вказувати `width` + `height` (no CLS).

#### 6.8 FOOTER
Footer = останній CTA, не сміттєзвалище посилань:
- Повторний CTA або міні-форма · Google Maps embed · Юридична адреса, ліцензія · Активні соціальні канали

### 7. HIGH-TICKET PREMIUM PATTERNS (B2B / Консалтинг / Агенції)
Для бізнесів з чеком $5,000+. Психологія ПРОТИЛЕЖНА секції 6: не "захопити всіх", а "відсіяти недостойних". Механіка multi-step форм (6.2), trust engineering (6.3) та visual rules (6.7) залишаються актуальними.

#### 7.1 VELVET ROPE EFFECT (Інверсія попиту)
Сайт НЕ продає і НЕ благає. Він працює як фейс-контроль:
- **ЗАБОРОНЕНО**: "Купити зараз", "Безкоштовна консультація", знижки, countdown таймери. Це руйнує преміум-позиціонування.
- **ОБОВ'ЯЗКОВО**: CTA = "Подати заявку" / "Перевірити, чи ви підходите" (Apply / See if you qualify). Статус послуги піднімається автоматично.
- **H1**: Не офер, а трансформація. "Ми перетворюємо B2B-компанії з $1M на $5M за 12 місяців" — конкретний результат для конкретної ніші. Жодних списків з 50 послуг.
- **Тональність**: "Заспокійливо дорого" (reassuringly expensive). Багато whitespace, стримана палітра, мінімум елементів.

#### 7.2 QUALIFICATION FORM (Відсіювання замість захоплення)
Замість відкритого Calendly або форми "Залиште телефон" — кваліфікаційна воронка:
- **Крок 1**: "Який ваш поточний масштаб/дохід?" (radio: <$100k, $100-500k, $500k-1M, $1M+)
- **Крок 2**: "Яка головна перешкода прямо зараз?" (open text)
- **Крок 3**: "Чи готові інвестувати від $X у вирішення?" (Yes/No — відсіює шукачів халяви)
- **Фінал**: Тільки після проходження → "Дякуємо, ми зв'яжемось протягом 48 годин" або календар.
- UX: Прогрес-бар, мінімалістичний дизайн, жодних відволікаючих елементів.

#### 7.3 ANTI-PERSONA ("Кого ми НЕ беремо")
Компонент з двома колонками:
- ✅ "Для кого це ідеально" — 4-5 пунктів з конкретними ознаками (масштаб, амбіції, готовність інвестувати).
- ❌ "З ким ми НЕ працюємо" — 4-5 пунктів (шукачі халяви, "хочу спробувати", немає бюджету). Парадокс: чим більше відмовляєш, тим більше хочуть.

#### 7.4 DEEP CASE STUDIES (Proof > Content)
Не карусель з текстовими відгуками, а глибинні кейси з хардкорними метриками:
- **Before → After**: конкретні цифри (Revenue: $200k → $1.2M, ROI: 340%, зекономлено 120 годин/міс)
- **Графіки/скріншоти**: реальні дашборди, аналітика (placeholder з description-prop для контент-менеджера)
- **Наратив**: не "клієнту сподобалось", а "проблема → рішення → результат за 90 днів"
- **Обмеженість**: показуй 2-3 найсильніших кейси, не 20 слабких

#### 7.5 QUIET LUXURY AESTHETICS
- Стримана палітра: 2-3 нейтральних тони + 1 тонкий акцент (не неон). Чорний, dark charcoal, кремовий.
- Whitespace > контент. Дозволяй сторінці "дихати" — порожнеча = дорого.
- Типографіка: тонкий serif для заголовків (editorial feel), чистий sans-serif для body.
- Мікро-анімації: тільки subtle (fade, parallax). Ніяких bouncing CTA чи пульсуючих кнопок.
- Scarcity UI: елегантний, не кричущий. "Беремо 2 клієнти на місяць · 1 місце вільне" — тихий текст, не червоний банер.

### 8. SCROLL-DRIVEN ANIMATION (Apple-Style Canvas)
> Розширена версія: `skills/apple-scroll-animation-architect/SKILL.md`

- **Формат**: ВИКЛЮЧНО Image Sequence на `<canvas>`. Заборонено `<video>` для скрол-анімацій
- **Кадри**: WebP only, 120-200 кадрів/секцію, FFMPEG екстракція: `ffmpeg -i vid.mp4 -vf "fps=30" -quality 80 frames/frame-%04d.webp`
- **Preloading**: Тотальне передзавантаження з батчингом по 15-20 (не 100+ паралельних)
- **Sticky Runway**: `.scroll-container { height: 400vh; }` + `.sticky-wrapper { position: sticky; top: 0; height: 100vh; }`
- **Anti-Jank**: НІКОЛИ `drawImage` всередині scroll handler. Scroll → лише `currentFrame`. Render → `requestAnimationFrame`
- **Overlays**: Прив'язувати контент до фаз скролу (progress діапазони), не до таймерів
- **ЗАБОРОНЕНО**: `<video>` для скролу, JPG/PNG для секвенцій, lazy load кадрів, scroll-handler rendering
