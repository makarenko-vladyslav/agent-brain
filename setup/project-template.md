# Шаблон CLAUDE.md для нового проєкту

Скопіюй цей шаблон як `CLAUDE.md` в корінь нового проєкту та заповни проєктно-специфічні секції.

---

```markdown
# <Назва проєкту> — Claude Code Instructions

## SuperBrain
Перед початком роботи прочитай `~/Projects/SuperBrain/CLAUDE.md` — глобальні правила, скіли та протоколи.

## Місія проєкту
<Одне речення — що робить цей проєкт і навіщо>

## Стек (якщо відрізняється від глобального)
<Специфічні технології цього проєкту>

## Dev Server
<Як запустити dev server, порт, логи>

## Production
<URL, хостинг, деплой команда, SSH доступ>

## Environment
<Який .env файл використовувати, особливості>

## Проєктно-специфічні правила
<Правила що стосуються ТІЛЬКИ цього проєкту — не дублювати глобальні>

## Верифікація (якщо відрізняється)
<Додаткові кроки верифікації специфічні для проєкту>

## Архітектурні рішення
<Ключові ADR або посилання на них>
```

---

## Принцип розділення

**В SuperBrain (глобально):** хто юзер, як працювати, які скіли, як вчитись
**В проєкті (локально):** що це за проєкт, де сервер, як деплоїти, специфічні правила

Якщо правило стосується ВСІХ проєктів → воно в SuperBrain.
Якщо правило стосується ТІЛЬКИ цього проєкту → воно тут.
